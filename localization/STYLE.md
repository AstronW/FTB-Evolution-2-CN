# 汉化约定

用户要求: 之前和之后的翻译全部使用英文标点.

- 所有自行编写的中文译文使用半角英文标点, 例如 `, . : ; ! ? ( ) [ ] " '`.
- 此规则适用于任务书, 手册, 新增物品名称/描述, 悬停提示及界面文案.
- 保留资源ID, API名称, 占位符, 命令, 链接, 可执行代码和原始英文源. 数学符号和单位不因标点规范而改写.
- 不直接修改模组JAR或自动下载的CFPA资源包. 对既有本地译文进行迁移, 对未来译文持续校验.
- 术语优先参考官方中文和 CFPA. CFPA 包括已合并仓库, 未合并 PR 及不同 Minecraft/模组版本的汉化; 跨版本候选核对当前英文源, 语言键与实际含义后复用. 冲突时按版本适配, 语义准确性, 模组术语体系与辨识度裁决, 不机械优先某一来源. 选定后同步游戏实际显示名称与任务书, 手册, 提示. 裁决维护见 `TERMINOLOGY.md`, 执行规范见根目录 `AGENTS.md`. 缺少中文的模组名称可以保留英文.

## 翻译范围

用户要求: 不为以建筑或装饰为主要内容的模组新增翻译, 包括普通语言与该类模组专属手册. 这些内容不计入计划完成范围内的待译缺口. 已有模组自带, CFPA 和项目译文继续保留.

普通语言的机器可读排除名单见 `language_scope.json`, 包括 Chisel, 装饰木格, FramedBlocks, Malisis Doors Reborn, Decorz, Connected Glass 和 Macaw 系列. 后续发现其他建筑或装饰模组时核实后补充名单. 科技或玩法模组中包含少量装饰方块, 不代表整个模组都要排除. 整合包任务书及必要的跨模组说明仍完整翻译, 不因引用排除模组而跳过章节; 也不因此展开其专属手册的翻译.
