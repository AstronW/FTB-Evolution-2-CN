## 用语与语义

- Starcaught Fish 为星钓鱼, Starcatcher's Rod/Guide 为星钓者钓竿/指南. Tackle Box 为渔具箱, Hook 为鱼钩, Bobber 为浮漂.
- 小游戏的 handle 为指针, sweet-spot 为判定区. 区分指针转速, 判定区移动速度, 消失速率, 逃脱进度, 未命中惩罚和鱼的耐力.
- 品质额外判定, 体型百分位, 完美捕获, 金色鱼与宝藏概率分别说明. 最低百分位判定保留取最小值的含义.
- 虚构鱼名按词义与描述命名, 如雷鸣鲈/电光鲈, 暗鳍鱼/苔鳍鱼, 晶背鱼类和机械鱼类. 创作者彩蛋音译并保留描述中的相关线索. 后续界面批次可复用 `value-translations.json`.
- 钓具效果中的 Dripstone Bait fish 结合鱼饵名称表述为溶洞鱼类. 瓶装信的数据组件错误与创造模式召唤限制完整保留.
- 物品描述原本按键分行, 译文仍按这些行呈现, 未将多行内容挪到一个键里.
- 全部自行编写译文使用英文标点. 原样保留 sclegendary, scepic, scuncommon 颜色标签和 §l 样式代码.
