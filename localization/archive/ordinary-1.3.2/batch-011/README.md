## 用语和语义复核

- 继续使用星钓鱼, 星钓者指南, 渔具箱, 鱼钩, 浮漂, 指针和判定区. 普通/罕见/稀有/史诗/传奇分别对应原有稀有度.
- 区分锦标赛重量/稀有度/金色计分模式, 百分位与完美捕获倍率. Simple 在渔具外观中为简约, 在计分规则中为简单, 按各自键的上下文处理.
- 导航菜单与统计标签虽然被手册引用, 也属于常用界面, 已一并覆盖. 季节, 天气, 月相, 高度, 光照与捕获上限保持各自含义.
- 漂流瓶的短行, 空行, 诗歌缩进与分段保留, 不把整封信挤入一个键. 防熔岩瓶子和海洋之心的颜色标签原样保留.
- 价格提示保留占位符与 50%% 的对应关系及顺序. 科学计数, 公制, 英制和趣味计量模式分别命名.
- 全部自行编写译文使用英文标点, 保留检查/叉号, 排序箭头, 占位符, 格式代码, 标签及边界空格.
