## 语义与术语复核

- 强化部件是消耗物, 爪式机械臂保留; 取消安装不消耗材料.
- 培养, 营养消耗, 衰老与恢复分别表述. 复制模板/配对菌落不消耗, 供料菌落消耗, 复制误差可能降低属性.
- 输入/抽取均以方块和网络的实际关系表述, 黑白名单与空过滤器行为保留原义.
- 固定占位符对应关系, 特别是产物名称与生长间隔, 物品数与传输间隔, 光束功率与纯度, 坐标与方向.
- `Conduit Tap` 在原生 `deep_engineering/current_conduits.md` 中是连接机器的物流接口, 统一为导管接口. 同步修正第 003 批名称. `Conduit Beacon` 是模拟原版潮涌核心效果的潮涌信标, 两者分别命名.
- 所有自行编写的译文使用英文标点, 保留 AP, AP/t, FE/t, mB/t, mB/s, 快捷键和数值.
