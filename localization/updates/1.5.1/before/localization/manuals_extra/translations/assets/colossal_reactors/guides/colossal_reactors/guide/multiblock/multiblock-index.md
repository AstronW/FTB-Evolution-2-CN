# 反应堆

反应堆是由**反应堆外壳**与**反应堆玻璃**(透明面)构成的中空壳体. 内部放置燃料**反应堆燃料棒**, 可选的**散热介质**, 可选的**冷却剂流体**, 外壳上的**端口**, 以及恰好一个驱动运行与屏幕读数的**反应堆控制器**.

**初次接触?** 请先阅读[入门](getting_started.md): **完整示例**, 然后是**方案 1**(仅 RF)或**方案 2**(冷却剂 → 涡轮机).
