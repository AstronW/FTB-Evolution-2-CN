# 切菜墩

切菜墩是一个手动加工站, 用于使用斧头劈切原木和其他物品.

<Row>
<ItemImage id="horsepowered:chopping_block" scale="4" />
</Row>

## 用法

1. 放置切菜墩.
2. 手持原木或其他可切碎的物品右键点击, 将其放到墩上.
3. 手持斧头右键点击以劈切物品.
4. 右键点击收集产物.

## 饥饿消耗

每次挥斧都会消耗少量基础饥饿值 (可配置). 部分配方还会在基础值之上追加自己的额外饥饿消耗, 且只有切菜墩会支付这部分消耗. 马匹切碎机则忽略它. JEI 会在带有饥饿消耗的配方上显示一行 "饥饿值", 方便你一眼看出哪些配方代价高昂.

## 备注

- 劈切时斧头可能会损失耐久 (可配置).
- 使用与马匹切碎机相同的配方, 除非配方被标记为仅限马匹.
- 手动劈切每个配方所需的挥击次数比马匹切碎多出一个可配置的倍率; JEI 会显示实际切碎次数.
- 可用的劈切配方可在 JEI/EMI 中查看.
