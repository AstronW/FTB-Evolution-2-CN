# 马匹磨石

马匹磨石是一台自动研磨机器, 由绕着它行走的马或其他生物驱动.

<Row>
<ItemImage id="horsepowered:grindstone" scale="4" />
</Row>

## 搭建

1. 把马匹磨石放在周围至少有 7x7 空旷空间的区域.
2. 用拴绳牵引一匹马 (或其他有效生物).
3. 手持拴绳右键点击磨石, 把生物拴上.
4. 生物会绕圈行走, 为磨石提供动力.

## 检查工作区域

空手**Shift+右键点击**磨石, 可显示所需的工作区域. 绿色 = 空旷, 红色 = 受阻.

## 用法

1. 手持物品右键点击, 将其放入磨石.
2. 拴上的生物会自动研磨物品.
3. 右键点击以取出产物.

## 备注

- 空手右键点击可释放拴上的生物, 并将其变回拴绳.
- 如果生物死亡或逃脱, 会掉落一根拴绳.
- 路径下方的地板会影响工作速度, 并且允许少量障碍物 (箱子, 漏斗等). 见[马匹路径与速度](horse_path.md).
- 默认的有效劳力: 马, 驴, 骡和羊驼. 可以通过配置添加其他生物.
