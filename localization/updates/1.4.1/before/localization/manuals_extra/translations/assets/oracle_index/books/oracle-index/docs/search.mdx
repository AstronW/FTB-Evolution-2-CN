---
title: 搜索
---

Oracle Index 具有智能搜索功能. 要打开搜索视图, 可以按 [CTRL + ORACLE_HOTKEY], 或按搜索快捷键(默认未绑定). 查看某个 Wiki 条目时, 也有一个小搜索图标.

<Callout variant="info">
    搜索还支持数学计算 / 表达式!
</Callout>

首次打开搜索界面时, 可能需要几秒钟为可用页面建立索引, 之后才能搜索. 该搜索是功能完备的语义搜索, 由机器学习驱动. 这意味着你不必使用精确的关键词搜索, 可以输入完整句子, 相关内容就会显示出来, 即使词语并不完全匹配. 任何相关主题都会显示.

## 技术细节
在底层, Oracle Index 会为所有页面生成嵌入, 这些页面会被预处理成多个块. 一个小型句子变换器模型 (all-MiniLm-L6-V2-q) 随后会为每个块以及搜索查询生成嵌入. 嵌入向量存储在内存中. 然后, 搜索查询的嵌入向量会与 Wiki 各块的嵌入进行比较. 最接近的 N 个结果随后会显示给用户.

用于此功能的库是 Langchain4j, 它使用 DJL 框架. 嵌入模型的大小约为 15mb.

## 限制

搜索会为基准语言的页面文本建立索引, 目前不会为译文单独构建语义索引. 选择结果时, 如果存在译文页面, 仍会打开该译文页面; 结果标题则使用当前语言.

嵌入模型和原生运行时会使启用搜索的构件更大. 如果已安装的平台构件不包含该运行时, Oracle Index 会报告搜索不可用, 并指向跨平台构件. 普通的 Wiki 浏览不依赖语义搜索.
