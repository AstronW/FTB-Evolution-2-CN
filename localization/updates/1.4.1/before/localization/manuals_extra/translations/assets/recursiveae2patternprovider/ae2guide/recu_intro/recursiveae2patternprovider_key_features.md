# 递归 AE2 样板供应器

## ✨ 主要特性

### 🎯 自动生成样板
- **智能依赖**: 即时自动创建缺失的合成原料样板.
- **递归逻辑**: 沿依赖链向下追踪, 直到配置的最大深度.
- **配方发现**: 只为具有有效且可求解配方的物品构建样板.
- **通用支持**: 为所有标准合成组件生成依赖样板.
- **兼容**: AE2, Extended AE2, Advanced AE 以及 ExtendedAE-Plus!

### ⚙️ 无缝 GUI 集成
- **终端内直接切换**: 使用专用按钮在样板编码终端内直接切换递归 (可通过 `enableEncodingGuiToggle` 配置).
- **专注合成样板**: 无缝集成到合成样板编码中, 在非合成模式下自动隐藏.
- **备选配方方式**: 支持通过工作台配方转换现有样板 (`Pattern + Iron Ingot`).

### 🎨 清晰的视觉反馈
- **原生提示框**: 显示与 AE2 原生提示框设计一致的 `Recursive` 标签.
- **持久标记**: 在终端中重新编码样板会保留其递归状态, 无需额外步骤.
