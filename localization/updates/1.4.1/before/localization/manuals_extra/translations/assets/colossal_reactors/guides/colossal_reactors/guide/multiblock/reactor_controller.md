# 反应堆控制器

<BlockImage id="reactor_controller" scale="4" />

当控制器位于外壳的**侧面**(不是顶部或底部)时, **右键点击**该方块即可打开它; 它会**替代外框上的一个外壳方块**, 屏幕朝**外**.

第一次接触多方块结构? 请从[入门](colossal_reactors:multiblock/getting_started.md)开始.

## 操作

- **验证 / 运行**: 首次打开时会执行验证; 验证有效后反应堆可以**开启**, 并显示 RF/tick, 燃料与冷却剂读数.
- **燃料**: 显示槽位时, 在你的物品栏与燃料棒储存之间移动燃料.
- **冷却剂流体**: 提供控件时可查看液位并进行填充/排空(使用空冷却剂缓冲区的**纯 RF** 玩法中可选).
- **重启**: 更改结构或端口设置后重新验证结构并刷新端口储罐大小.

## 在不破坏多方块的情况下停止

如果希望用外部红石**暂停**或**停止**运行而保持外壳成型, 请使用[反应堆红石端口](redstone_port.md). **没有**红石端口时, 反应堆只要有效且**开启**就会运行(没有红石门控).

如果你的整合包启用了**稳定性**读数, 它们会显示在这里; 见[反应堆不稳定性](reactor_instability.md).

## 反应堆有效但不产出?

| 检查项 | |
|-------|---|
| 能量端口存在且已连线? | RF 需要一个[能量端口](power_ports.md), 且其**外侧**有能接受能量的设备. |
| 纯 RF 模式? | 空冷却剂缓冲区 = 不需要流体; 水/蒸汽模式需要冷却剂 + 抽取路径. |
| 红石端口? | 在端口模式 + 信号允许运行之前, 反应堆可能一直**关闭**. |
| 废料堆积? | 添加一个**抽取**型[资源端口](resource_port.md), 或手动清空废料. |

此界面上的提示与状态行会说明当前状态.
