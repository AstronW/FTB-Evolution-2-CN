---
title: 用户指南
---

Oracle Index 是一个游戏内客户端文档模组, 旨在作为 [moddedmc.wiki](https://moddedmc.wiki/) 内容的游戏内视图.

模组开发者可以选择将他们的 Wiki 包含在模组中, 然后使用 Oracle Index 模组在游戏内显示. 按下 Wiki 快捷键(默认为 [H])即可打开 Oracle Index 界面.
你不需要特殊的书类物品或任何东西. 退出界面时, 它会记住你上次看到的位置.

只有当模组已安装, 且模组开发者选择将其来自 moddedmc.wiki 的文档也作为 Oracle Index Wiki 包含时, 你才能查看该模组的文档.

## 模组切换
在界面左侧, 你会看到当前所选模组的导航栏. 要切换到其他模组, 只需点击导航栏上方的模组标题栏.
会打开一个下拉菜单, 你可以在其中选择要浏览的模组.

## 物品链接
模组开发者可以为游戏内物品添加 Wiki 链接. 如果某个物品有对应的 Wiki 页面, 你会在物品提示中看到一小段额外内容.
在查看物品提示时按住 [ALT] 键, 即可打开对应的 Wiki 条目.

## 语言
当 Wiki 提供对应内容时, Oracle Index 会自动使用与你的 Minecraft 语言完全匹配的译文. 页面内容, 导航元数据, 页面标题, 内置控件, 标注以及状态消息都可以翻译.

在 schema 1 的 Wiki 中, 译文页面会在 `translated/<locale>/` 下镜像基础页面路径; 在旧版 Wiki 中则位于 `.translated/<locale>/`. 当译文页面或元数据文件缺失时, Oracle Index 会回退到基准语言资源.

搜索目前会为基准语言的页面文本建立索引. 当存在译文页面时, 结果仍会打开该译文页面; 显示的页面标题则使用当前语言.
