- Forced All/None 是盟友设置, 翻译为强制全部结盟/强制不结盟, 不误作区块加载开关.
- 队伍长期无人登录与强制加载过期分别处理. 明确 0 表示禁用自动释放/过期, 或在对应硬上限字段中表示无硬限制.
