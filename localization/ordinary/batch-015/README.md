# 第 015 批: Roots Classic 既有中文迁移与补齐

覆盖当前 JAR 的全部 496 个原生键, 对应 433 个不同原文值. 487 个键含中文, 9 个为空字符串. 本批复用并复核自带中文 453 键, 补齐其余 43 个未收录键, 其中包括空占位键. 静态缺口减少 487, 主要来自已有译文恢复为可解析覆盖, 不代表新翻译了 487 个键.

原生中文存在未转义制表符, 导致严格 JSON 解析失败. 本批仅在导出时容许读取该字符, 转为普通空格并输出合法 JSON. 不能仅凭静态解析失败断言原文件完全无法被 Minecraft 加载. 原 JAR 不修改.

输出安装于 `.minecraft/kubejs/assets/rootsclassic/lang/zh_cn.json`, 共 496 键. 原先没有本地覆盖, `overlay-before.json` 为空对象. 自带中文快照, 规范化参照与迁移统计分别保存于 `upstream-zh_cn.json`, `normalized-upstream-by-key.json`, `repair-statistics.json`.

- 补齐樱花木/红树木/苍白橡木树皮, 去皮刀提示, 客户端与魔法配置, JEI 仪式说明等遗漏项.

- 本批迁移包含自带研究/手册文本, 复核其数值和主要操作条件. 修复金合欢拼写, 凋灵与剩余次数等旧译问题, 补回生长粉末和水流法术遗漏的 4 格距离, 去掉原中文额外加入而英文没有的格式代码.
