# 第 023 批: CakestickLib 全部原生语言键

CakestickLib 1.17.5 的 JAR 只有 `en_us.json`, 无任何中文, 也没有对应 CFPA 命名空间. 本批覆盖全部 268 个原生键, 对应 249 个不同原文值, 268 键均含中文, 无保留英文条目.

内容包括材料与流体名, 矿石与碎块, 粉末/板/箔/齿轮等加工件, 模具, 升级与扳手类工具, 以及进度标题和界面提示.

## 术语

- 金属与合金: Steel 钢, Wrought Iron 熟铁, Advanced Alloy 高级合金, Mixed Ingot 混合锭. 沿用任务书与既有科技模组的钢/熟铁区分, 不把 Wrought Iron 译为锻铁.
- 流体: 熔融铜, 熔融金, 熔融铁, 熔融钢, 熔融下界合金, 熔融远古残骸, 熔融荧石, 熔融红石; 原油, 胶水, 蜂蜜, 乳胶, 液态玻璃, 塑料, 树脂, 树液, 硫酸. 一律采用熔融 X 的 Minecraft 既有说法.
- 加工件: Dust 粉, Plate 板, Foil 箔, Gear 齿轮, Nugget 粒, Ingot 锭, Coil 线圈, Bolt 螺栓.
- 模具统一为 X模具: 锭模具, 粒模具, 板模具, 条模具, 块模具, 箔模具, 齿轮模具, 棒模具, 空白模具. 不写作铸模, 以免与 Tinkers 体系混同.
- 方块与石材沿用原版译名: 安山岩, 闪长岩, 花岗岩, 深板岩, 凝灰岩, 黑石, 末地石, 下界岩, 滴水石; 碎块为 X碎块, 卵石为 X卵石.
- 矿石名按矿物学常用名: 辉银矿, 金银矿, 铝土矿, 锡石矿, 黄铜矿, 方铅矿, 赤铁矿, 高岭土, 褐煤, 孔雀石, 锇铱矿, 镍黄铁矿, 辉橄岩, 石英岩, 沥青铀矿, 圆柱锡矿.
- Xenothite 为虚构矿物, 音译为泽诺石, 条目作泽诺石矿; Molten Blazing 缺少可核验语义, 按字面作熔融烈焰. 两项均记入 `TERMINOLOGY.md`, 后续若在手册或配方中发现其他含义再复核.

## 格式

保留全部 `§` 格式代码及其顺序, 例如 `§7`, `§f`, `§a`, `§c`, `§8§o`, `§b§l`. 保留下划线占位符与数值: `§7Drop §f0-2§7 items every scrape` 的 0-2 未改, `Status: §cInactive` 的前缀与颜色码保持不变, `BlockPos : ` 等带尾部空格的拼接串保留空格.

`cakesticklib.configuration.min_mb_cost` 的原文写作 MB (大写), 译文同样保留 MB, 未改成 mB, 以免与校验单位表和原文不一致.
