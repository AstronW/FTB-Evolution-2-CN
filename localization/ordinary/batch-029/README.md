# 第 029 批: FTB Industrial Contraptions 官方中文缺口

FTB IC 的 JAR 自带 `zh_cn.json`, 802 个原生键中已有 427 个中文. 本批补齐其余 147 个普通语言键, 对应 127 个不同原文值, 136 键含中文; 11 键为界面格式串与单位, 原样保留: `%s/%s`, `= %s`, `%s: %s`, `%d%%`, `I/O`, `%s (%s): %s`, `%s FE`, `%s FE/t`, `%s zaps`, `%s z/t`, `%s / %s`.

内容为金属块与矿石, 粉/齿轮/板/棒/导线系列, 配置卡提示, 机器界面槽位与单位, 以及机器音效字幕.

## 术语

- 金属沿用既有科技体系: 铝, 青铜, 钢, 铅, 镍, 银, 锡, 铀, 铱, 钚; 合金为康铜, 琥珀金, 殷钢.
- 原版材料用官方名: 下界合金, 黑曜石, 绿宝石, 青金石, 石英.
- 形态后缀统一: 块, 粗X块, 粗X, 矿石, 深层X矿石, 粉, 齿轮, 板, 棒, 导线.
- Cable 与 Wire 区分: 方块与物品的 Superconducting Cable 为超导线缆, 材料导线为 X导线, 不混用线缆.
- 加工产物: Crushed/粉碎, Washed/洗净, Refined Concentrate/精炼精矿, 保留原料名占位.
- 机器名取官方既有译名: 离心机, 压缩机, 打粉机, 核反应堆, 核反应仓, 电力工作台, 反应堆模拟器.

## 格式

- 界面格式串与能量单位 `FE`, `FE/t`, `zaps`, `z/t` 不翻译, 避免与数值拼接或工具提示冲突.
- `%d%%` 的百分号转义保留, 反应堆热量百分比显示不受影响.
- 方向按钮 `I/O` 保留, 与配置卡中的面配置一致.
- 字幕为动作描述而非台词, 使用动词短句: 离心机旋转, 压缩机压合, 打粉机研磨等.
