# 第 060 批: Energized Power 手册语言键

Energized Power 的指南正文以语言键承载 (`book.energizedpower.page.*`), 官方 `zh_cn` 中这 60 个键仍是英文. 本批补齐它们, 对应 55 个不同原文值, 58 键含中文; 2 键为外链名称 `Discord` 与 `Reddit`, 保留原文.

这一批属于手册正文, 但因为是语言键, 仍用普通语言的构建与校验流程; 统计上计入手册语言键, 不计入普通文本.

## 术语

沿用第 021 批已定的名称, 保证同一模组内一致:

- 充能器, 充能速度升级模块, 能量容量升级模块, 能量产出升级模块, 持续时间升级模块.
- 物品弹出升级模块, 物品吸取升级模块, 经验提取升级模块, 经验汲取, 经验存储器, 液态经验.
- 流体冷冻机, 机器配置器, 输入输出配置, 槽位组, 槽位类型.
- 机器框架五级: 基础, 硬化, 高级, 强化高级, 精英; 太阳能板四级: 基础, 高级, 强化高级, 精英.
- 变压器等级保留 LV, MV, HV, EHV, UHV; CCTweaked 保留原名.

## 格式

- `book.energizedpower.page.io_configuration.9.x.x` 是跨键拼接的句子片段, 原文以空格开头, 译文保留前导空格, 否则颜色词与后续从句会粘连.
- 数值与顺序保留: `3`/`7` 个槽位, `6` 个侧面按钮, 信号强度 `1`, `0` 刻, `15`, `14/15`, 天气 `15/14/13/1 - 12`, 以及 `VI 级`.
- `Discord` 与 `Reddit` 作为外链名称不译; `Subreddit` 译为子版块.

## 验证

- `python localization/ordinary_translation.py batch-060 --build`: 英文源与 JAR 一致, 55 个值全覆盖, 占位符, 数值顺序, 格式代码, 单位, 换行与边界空格检查通过.
- 输出合并进 `.minecraft/kubejs/assets/energizedpower/lang/zh_cn.json`, 该文件现含 455 键 (第 021 批 395 + 本批 60).
- 未修改 JAR, CFPA 资源, 配方或存档.
