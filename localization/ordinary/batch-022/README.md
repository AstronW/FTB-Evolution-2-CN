# 第 022 批: Logistics Networks 物流服务器与网络图界面

本批补齐 Logistics Networks 1.13.0 的 277 个普通语言键, 对应 266 个不同原文值, 256 个键含中文. 21 个键保留非正文值, 包括 `mB/s`, `RF`, `SRC`, `/s` 等计量单位, `%s %s,%s,%s` 坐标格式, `A-Z`/`Z-A` 排序标识, `NBT`, `AE2`, `RS` 缩写与字母图标 `i`, 均登记在 `manifest.json` 的 `unchanged_values`.

JAR 自带 `zh_cn` 477 键, 但缺这 277 键 (其中 15 键与英文同值, 全为计量单位). 本批只输出缺口, 不改写既有中文; 术语沿用其既有译名.

## 内容

- 物流服务器方块与容器, 两侧选择网络, 频道链接与状态提示 (含共用资源类型, 无输出方向等诊断).
- 电脑端的输入输出监视器: 吞吐量时间轴, 平均值与峰值, 时间窗, 滚动分页, 速率与传输量悬停.
- 网络图编辑器: 节点排列, 框选与多选, 成员与共享设置, 跨维度路线, 频道类型与输入输出模式, 标签组的加入/替换/移除确认.
- 扳手设置: 外壳与屏幕配色, 流动线的资源/频道/网络筛选, 路径与直线样式, 粗细, 速度, 不透明度, 脉冲间距与长度, 穿墙显示, 模式轮盘.
- 存储集成: 链接 AE2 与精炼存储, 网络升级, 自动合成放置节点, 批量放置, 合成失败与处理器状态原因, 标签同步与回滚.
- 标签选择器: 分组检索, 按字母或数量排序, 内容预览, 匹配计数, 每槽一标签.
- 管理员模式与网络删除确认.

## 术语

沿用 JAR 内既有中文, 新名称按同一体系补齐:

- Network 网络, Node 节点, Channel 频道, Label 标签, Wrench 扳手, Filter 过滤器, 既有.
- Channel 模式沿用官方的输入/输出, 不采用导入/导出, 与 `channel_mode.import/export` 一致.
- 频道类型: 物品, 流体, 能量, 化学品, 魔源; Source 取官方的魔源, 不译作源.
- 分配模式: 优先级, 最近优先, 最远优先, 轮询分配; 本批新增 Priority Robin 为优先级轮询.
- 节点设置: 单次数量, 延迟, 优先级, 分配, 过滤模式, 面, 红石, 均沿用官方.
- 升级: 铁级/金级/钻石级/下界合金级/跨维度升级为既有; 本批新增网络升级与 `%s 升级` 占位形式.
- 存储: Refined Storage 为精炼存储, AE2 保留原名.
- Tag 统一为标签, 与既有 `.lnet` 标签体系一致, 不译作标签页或标记.

## 标点与格式

本批自行编写译文使用英文标点; 既有官方中文的全角标点保持原样. 以下格式按原样保留:

- 计量单位与速率 `mB/s`, `RF/s`, `SRC/s`, `mB`, `RF`, `SRC`, `%s mB`, `%s RF/t` 不译, 避免与界面数值拼接冲突.
- `%s %s,%s,%s` 与 `%s-%s / %s` 为坐标与分页格式, 不改写逗号与斜杠.
- `Rate: %s %s` 保留两个占位符与顺序; `-%ss` 转为 `-%s 秒`, `%st` 转为 `%s 刻`, 数值位置不变.
- `Avg %s · Peak %s` 保留中点符号, 与官方界面的中点用法一致.
