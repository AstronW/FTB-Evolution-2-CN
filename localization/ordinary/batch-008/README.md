## 术语与语义

- 沿用任务书的奥术纲要, 洞察之眼, 铭文台, 祭坛核心, 方尖碑, 天体棱镜, 黑暗灵球, 温特姆, 奇美拉石, 日光石, 月长石和女巫木.
- 亲和元素, 能力, 法术部件和预设法术分别命名, 配置批次将使用相同术语. Etherium 为源质, Mana 为魔力, Burnout 为魔力负荷.
- 技能名称即使被手册引用, 也作为普通玩法名称一并翻译. 只将长篇手册说明留给手册工作.
- 用原生纲要中 transplace, mana_blast, life_tap 等说明复核名称, 分别译为换位, 魔力爆破和生命分流.
- 祭坛材料界面的 Power (Cap) 指顶饰贡献的强度, Power (Structure) 指建筑材料贡献的强度, 不误作储能容量.
- 指令中的数量, 玩家与亲和参数保持对应顺序. 守护者伤害标签区分治疗, 免疫和易受伤害.
- 所有自行编写译文使用英文标点. 保留占位符, 数字, 快捷键和拼接边界空格.
