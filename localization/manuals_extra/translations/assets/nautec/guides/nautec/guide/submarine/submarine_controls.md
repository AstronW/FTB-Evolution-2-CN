# <Color id="light_purple">驾驶</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="submarine" scale="2"/>
  按键, 转向和读数.
</Column>

驾驶员用常规移动键驱动海洋侦察艇, 并通过视线转向, 同时获得能量与艇体读数, 以及替代快捷栏的模块栏.

***

## <Color id="gold">按键</Color>

| 按键(默认) | 作用 |
|---|---|
| W | 向前推进 |
| S | 倒退, 推力减半 |
| 按住疾跑(Ctrl)的同时按 W 或 S | 推力增加 60% |
| 鼠标 | 转向: 艇首跟随你的视线 |
| 空格 | 上浮 |
| C | 下潜 |
| 按住鼠标右键(使用) | 自由观察: 环顾四周而不改变航向 |
| 1 到 9, 或鼠标滚轮 | 选择模块槽 |
| 鼠标左键, 或 F | 发射所选模块 |
| Ctrl + H | 移动读数 |
| 潜行(Shift) | 爬出 |

C, F 和 Ctrl + H 是 海蓝科技 的按键绑定, 在控制设置中分别列为 海洋侦察艇下潜, 发射海洋侦察艇模块 和 调整海洋侦察艇 HUD 位置. 可在那里重新绑定. 驾驶时, F 只会发射模块, 因此不会交换副手或切换水流喷射器的灯.

***

## <Color id="gold">转向</Color>

没有转向键. 艇体会跟随你的视线转动, 在水下可上下俯仰达 75 度. 自由观察后松开鼠标右键, 视线会立刻回到艇首方向.

艇体只在有空间时才会转向. 如果视线指向岩石, 它会保持航向而不会穿模, 因此在狭窄洞穴中转向之前要先后退或上浮. 转向时, 它的碰撞箱会跟随艇体的真实形状. 它只与方块碰撞: 挡路的鱼和其他生物会被推开.

在水面上, 艇体保持水平, 推进器只有约三分之一的推力, 上浮和下潜也更弱. 想要速度, 先潜到水下.

安装[飞行模块](flight_module.md)后, 艇体可以飞行: 出水后它的转向和俯仰与水下完全相同, 空格和 C 以全功率上浮和下潜, 移动速度也快一半.

推进需要能量. 电池耗尽时, 艇体只能漂流.

乘艇时第三人称相机位于后方 10 格处, 以便看到整个艇体. 该距离可配置(`submarineCameraDistance`).

***

## <Color id="gold">读数</Color>

坐上驾驶座后, 屏幕上会出现一个面板, 包含两行: 代表电池的 PWR 和代表艇体的 HULL, 各自带有百分比. 面板下方列出操作方式.

* PWR 低于 20% 时闪烁, 电池耗尽时显示 CHG.
* HULL 低于 35% 时变红, 低于 15% 时闪烁.

驾驶时, 该面板会替代原版的载具生命值, 快捷栏和经验等级. 九个模块槽会取代屏幕底部的快捷栏(见[模块](submarine_modules.md)).

随时按 Ctrl + H 可打开定位界面, 将面板拖到想要的位置, 再按 Esc 或 Ctrl + H 保存. 位置会保存在客户端配置中.

后座乘客看不到这些内容, 仍使用正常快捷栏.
