# 维度资源指南手册

## 维度资源

维度资源是一个允许你发现行星, 并使用激光器从行星上开采资源的模组!

## 入门

首先, 你会在世界中找到一种名为维度矿石的新矿石, 它生成在世界深处 -16 到 -64 之间.开采这种矿石会获得维度碎片, 这是本模组的核心原料.
<Row>
    <BlockImage id="dimresources:deepslate_dimensional_ore" scale="4" />
    <BlockImage id="dimresources:dimensional_ore" scale="4" />
</Row>

接下来, 你需要合成一个望远镜和一个行星定位器
<Row>
    <Recipe id="minecraft:spyglass" />
    <Recipe id="dimresources:planet_locator" />
</Row>
将行星定位器拿在副手, 同时使用望远镜观察天空以寻找行星!发现行星后, 行星定位器会被设置为该行星.
