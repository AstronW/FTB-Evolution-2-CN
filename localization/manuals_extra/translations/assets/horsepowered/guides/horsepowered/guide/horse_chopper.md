# 马匹切碎机

马匹切碎机是一台由马或其他生物驱动的自动切碎机器. 它无需人工干预即可持续切碎原木和其他物品.

<Row>
<ItemImage id="horsepowered:chopper" scale="4" />
</Row>

## 搭建

1. 把马匹切碎机放在周围至少有 7x7 空旷空间的区域.
2. 用拴绳牵引一匹马 (或其他有效生物).
3. 手持拴绳右键点击切碎机, 把生物拴上.
4. 生物会绕圈行走, 为切碎机提供动力.

## 检查工作区域

空手**Shift+右键点击**切碎机, 可显示所需的工作区域. 绿色 = 空旷, 红色 = 受阻.

## 用法

1. 手持原木或其他可切碎的物品右键点击以放入.
2. 拴上的生物会自动切碎物品.
3. 右键点击以取出产物.

## 备注

- 切碎机有两格高.
- 与手动的切菜墩不同, 不需要斧头.
- 漏斗可以从顶部或侧面输入, 并从底部抽出成品.
- 空手右键点击可释放拴上的生物.
- 路径下方的地板会影响工作速度. 见[马匹路径与速度](horse_path.md).
