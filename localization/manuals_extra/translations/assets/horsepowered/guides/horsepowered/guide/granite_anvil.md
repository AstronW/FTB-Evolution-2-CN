# 花岗岩铁砧

花岗岩铁砧是一个手动破碎站, 用于把较硬的材料打碎成更小的碎块. 用石质或更好的镐敲击放置的物品, 可以把石头破碎成圆石, 把圆石破碎成沙砾, 等等.

## 用法

1. 放置花岗岩铁砧.
2. 手持石块或其他可破碎的物品右键点击, 将其放到铁砧上.
3. 手持石质 (或更好) 的镐右键点击以破碎物品. 每个物品需要多次敲击.
4. 完成的产物会在铁砧处掉落, 或留在内部槽位中 (可配置).

## 饥饿消耗

每次敲击都会消耗少量基础饥饿值 (可配置). 部分配方还会在基础值之上追加自己的额外饥饿消耗. JEI 会在带有饥饿消耗的配方上显示一行 "饥饿值", 方便你一眼看出哪些配方代价高昂.

## 备注

- 木镐强度不足. 铁, 金, 钻石和下界合金镐也可以使用.
- 镐在每次敲击时都会损失耐久 (可配置, 受耐久附魔影响).
- 破碎进行中时, Jade 会显示剩余敲击次数.
- 可用的破碎配方可在 JEI/EMI 中查看.
