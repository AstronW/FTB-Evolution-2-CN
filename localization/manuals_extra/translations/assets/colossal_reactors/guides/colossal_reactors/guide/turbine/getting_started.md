# 入门: 你的第一台涡轮机

建造一个封闭的涡轮机外壳, 内部装有转子和线圈, 然后从下面两种方案中选择一种. 旋转场景以查看各个面.

## 外壳布局

- **地板和屋顶**: **涡轮机外壳**(封闭框架).
- **竖直边角**: 四条边缘处的 **涡轮机外壳** 立柱(y=1-5).
- **西, 东和南墙**: 每个面上一块 **5×5 涡轮机玻璃** 面板.
- **隔墙**位于**转轴控制器高度**(示例中 y=3): 内部为 **涡轮机外壳** 环, 侧墙上为**外壳带**; 这一行会**横穿**那三个面上的 5×5 玻璃.
- **控制器面**(示例中为北面): **涡轮机控制器** 作为**单个方块**向外凸出; 该面上未放置端口的其余格子使用 **涡轮机玻璃**. **端口会替换**该墙上的玻璃, 布局与[反应堆示例](../multiblock/getting_started.md)相同.
- **线圈区域**(隔墙上方): 内部顶部的**两层**(示例中 y=4-5), 即紧贴屋顶外壳下方的**铜块**.
- **转子区域**(隔墙下方): **两段转轴**(y=1-2); 下层环上**四片叶片**, 上层段上两个环共**八片叶片**; **涡轮转轴控制器** 位于隔墙层(y=3).

[涡轮机建造器](turbine_builder.md) 会放置外壳, 转子和线圈, 但**不会**放置控制器或端口.

## 线圈

**线圈区域**是隔墙上方的**内部上层**(屋顶之下). 必须用模组可识别的**金属存储方块**填充: 铜, 金, 下界合金, 琥珀金等.

| | 详情 |
|---|---|
| **作用** | 多倍提升来自蒸汽的 **RF**(下式中的 `coil strength`) |
| **位置** | 隔墙**上方**的内部层, 不是转子/叶片空间 |
| **使用什么** | 普通**存储方块**(例如铜块). 在 **JEI** 中查看强度和上限 |
| **不要使用** | 反应堆**加热线圈**方块, 那是另一种机器部件 |
| **空位** | 仍会作为弱线圈通过验证(默认约 **30%** 强度) |
| **层数** | 示例使用**两层**; [涡轮机建造器](turbine_builder.md) 可设置层数 |

混合金属没有问题, 涡轮机使用整个区域的**平均**强度. 完整数值见[蒸汽, RF 与线圈](turbine_generation_and_coils.md).

## 效率: 影响 RF 输出的因素

当涡轮机**结构正确**且**正在运行**时, 每 tick 的 RF 遵循:

**RF/t** ≈ 消耗的蒸汽 × **每 mB RF** × **线圈强度** × **叶片布局加成**

完整分解见[蒸汽, RF 与线圈](turbine_generation_and_coils.md). 简而言之:

- **蒸汽供应**: 受叶片数量和布局限制; 更均衡的环 → 更高的蒸汽/tick.
- **线圈方块**: **内部上方两层**中的金属存储方块(铜, 金, 下界合金等). 空线圈格视为弱线圈(约 30% 强度); 方块数值见 JEI.
- **叶片高度加成**: 越靠近隔墙, 叶片越多的环, 每上升一层获得 **+3%**; 逐层收缩的环损失 **−3%**. **高效**与**高产**布局有影响, 见[转轴与叶片](turbine_rod_and_blades.md).
- **有效结构**: 外壳, 线圈, 转轴控制器和端口都必须通过验证, 才会开始发电.

## 方案 1: 简单能量(独立蒸汽)

当**蒸汽已经存在**(储罐, 其他模组, 创造模式)且你只需要**涡轮机产生的 RF** 时使用.

1. 建造外壳, 转子(转轴 + 叶片), 线圈和**转轴控制器**, 或使用[涡轮机建造器](turbine_builder.md).
2. 按示例在同一个面上放置**控制器 + 三个端口**(控制器在**外部**, 端口**分散**在同一面).
3. 配置**两个资源端口**: **INSERT**(蒸汽输入)和 **EXTRACT**(水/用过的流体输出). 两者都在**外部**接管道.
4. 将**能量端口**的外部面连接到能量接收方.
5. 打开控制器 → **有效** → **开启**; 检查 **RF/t** 和蒸汽消耗.

| 端口(示例位置) | 模式 | 作用 |
|------|------|------|
| 控制器面左下 | 资源端口: **INSERT** | 蒸汽**输入** |
| 控制器面右下 | 资源端口: **EXTRACT** | 水/排出物**输出** |
| 中央列, 控制器下方一格 | 能量端口 | RF **输出** |

在 GUI 中配置**两个资源端口**; 悬停每个按钮可查看提示([完整列表](turbine_resource_port.md)). 更改端口模式或转子布局后执行**重启**.

## 方案 2: 冷却剂链(反应堆蒸汽)

与[反应堆入门: 方案 2(冷却剂)](../multiblock/getting_started.md)配合使用: 裂变反应堆产生**蒸汽**, 涡轮机将其转化为**更多 RF**.

1. 按方案 1 建造涡轮机(外壳, 转子, 线圈, 控制器, 端口都在**一个**面上).
2. 在反应堆上执行**方案 2**: 向控制器输入冷却剂, 在**与反应堆控制器相同的面**上 **INSERT** 冷却剂并 **EXTRACT** 蒸汽/用过的流体.
3. 将**蒸汽**从反应堆的 **EXTRACT** 端口 → 涡轮机的 **INSERT** 资源端口. 将**水**从涡轮机的 **EXTRACT** 资源端口送往储罐, 或送回反应堆冷却剂回路.
4. 从涡轮机的**能量端口**获取 **RF**(反应堆能量端口是可选的备用 RF).

让涡轮机尺寸和叶片数量匹配反应堆的蒸汽输出; 见[蒸汽, RF 与线圈](turbine_generation_and_coils.md). 如果蒸汽积压, 增加容量, 建造更大的涡轮机或增加叶片.

## 检查清单

1. 封闭外壳: 外壳地板/屋顶, 边角立柱, 三面墙上的 **5×5 玻璃**(**y=3** 处的隔墙切过一行); 控制器面使用**玻璃 + 端口**.
2. 隔墙下方有有效的**转子**: **两个转轴方块**(y=1-2), 下层环上 **4 片叶片**, 上层段 **8 片叶片**(两个环), 顶部还有**两层线圈**(y=4-5, 例如铜块).
3. **一个[涡轮机控制器](turbine_controller.md)** 单独位于箱体**外部**.
4. 控制器面上有**两个资源端口 + 一个能量端口**(该面上任意位置).
5. 选择**方案 1**(任意蒸汽源)或**方案 2**(反应堆冷却剂回路).
6. **红石端口**是可选的.

## 涡轮机建造器(可选)

1. 建造器只放置**外壳 + 转子 + 线圈**.
2. **停止**建造, 然后按场景在**一个**面上添加控制器(外部)和端口.
3. 从控制器验证.

## 涡轮机无法运行?

| 症状 | 可能原因 |
|---------|----------------|
| 状态为**无效** | 修正外壳, 转轴, 叶片, 线圈或转轴控制器(查看状态行). |
| **开启**但 RF/t 为 0 | 没有蒸汽供应, 没有能量端口, 或没有能量接收方. |
| 相对输入蒸汽而言 RF 过低 | 叶片/线圈数量不足以匹配蒸汽速率; 见[转轴与叶片](turbine_rod_and_blades.md). |
| 不消耗蒸汽 | 资源端口未设为 **INSERT**, 或管道接在了错误的一侧. |
| 水积压 | 缺少 **EXTRACT** 资源端口, 或外部没有储罐/管道. |
