# 反应堆不稳定性

某些整合包会在普通反应堆运行之上启用额外的**不稳定性 / 压力**层. 当它对你的存档生效时, **反应堆控制器**的 HUD 与读数会显示与稳定性相关的警告或限制: 请遵循这些提示, 并按界面指示调整燃料, 冷却剂或布局.

散热介质与冷却剂定义包含乘数, 仅在 **common** 配置中开启不稳定性时影响该层.

如果你的控制器从未提及不稳定性, 可以忽略本主题.
