# 1.4.0 普通语言旧批次输入适配

2026-10-17, 目标实例从 `project.json` 读取, 已核对实例 1.4.0 / Minecraft 26.1.2. 本次修复第 002-007、010-011、016-017 批的旧 JAR 路径失败, 不扩大为全量普通语言翻译或整包适配完成.

原来覆盖整份语言文件的第 002、006、007 批改为显式列出当前有效的既有语言键. 新增 36 键的完整键名与英文保存在同名 JSON 的 `pending_added_keys`, 不计入本次已完成范围. 第 007 批的旧名称保留在可维护归档、JSON 兼容记录及本地中文覆盖中, 不将它们当作当前 JAR 原生键, 也不据此推断流体/物品已删除. 未增加或修改术语, 合理英文保留继续按原批次逐项清单验证.

修改前清单、源文、值索引、译文、检查结果和说明已逐批保存在 `localization/archive/ordinary-1.3.2/`. 重新从目标 JAR 读取英文并逐键比对后更新当前清单与快照, 未伪造旧 JAR 文件名, 未关闭断言. JSON 记录当前 JAR 和语言文件 SHA-256、源文差异与旧文件路径. 原 `prefill.json`、`new-values.tsv` 等提取辅助文件保留为历史参考, 当前构建以 manifest、source-en_us、source-values 和 zh-values 为准.
