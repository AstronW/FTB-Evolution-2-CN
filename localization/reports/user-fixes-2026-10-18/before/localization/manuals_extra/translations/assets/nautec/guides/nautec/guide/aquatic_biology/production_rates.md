# <Color id="light_purple">生产速率</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="minecraft:clock" scale="2"/>
  菌落在反应机中制造物品的速度, 以及所需的能量.
</Column>

这里的数值适用于[生物反应机](bio_reactor.md)和[工业生物反应机](industrial_bio_reactor.md)两者. 工业生物反应机并不会让每个菌落更快; 它只是用更多升级运行更多菌落.

***

## <Color id="gold">公式</Color>

每个 tick, 工作中的菌落都会增加进度:

每 tick 进度 = 生产速率 x 规模系数 x 基础速度 x 菌株产量 x 速度加成

* 生产速率是菌落的属性, 最高为 2([细菌属性](bacteria_stats.md)).
* 规模系数为 0.5 + 0.5 x 规模 / 40,000, 因此微小菌落为 0.5, 规模上限时为 1.
* 基础速度在两种反应机中都是 16.8, 可分别配置.
* 菌株产量属于菌株, 见下表.
* 速度加成为 1, 每个[反应机速度升级](reactor_upgrades.md)再加 0.5.

每 100 点进度完成一个循环, 把 1 个物品放入菌落的输出槽, 每有一个反应机产量升级再加 1 个. 剩余的进度会带入下一个循环. 一分钟是 1,200 tick, 因此:

每分钟物品数 = 每 tick 进度 x 12 x 每循环物品数

JEI 的生物反应机分类和已分析培养皿的悬停提示都会显示菌株的菌株产量. 整合包可以通过菌株 json 中可选的 `production_multiplier` 字段设置它, 默认值为 1.

## <Color id="gold">计算示例</Color>

一个达到属性上限(生产速率 2, 规模 40,000)且没有升级的菌落:

| 菌株产量 | 每 tick 进度 | 每件物品耗时 | 每分钟物品数 |
|---|---|---|---|
| 1(石头) | 33.6 | 0.15 秒 | 约 403 |
| 0.8(煤, 铜) | 26.9 | 0.19 秒 | 约 323 |
| 0.6(铁) | 20.2 | 0.25 秒 | 约 242 |
| 0.5(红石, 青金石) | 16.8 | 0.3 秒 | 约 202 |
| 0.4(金) | 13.4 | 0.37 秒 | 约 161 |
| 0.12(钻石) | 4.03 | 1.2 秒 | 约 48 |
| 0.1(绿宝石) | 3.36 | 1.5 秒 | 约 40 |

新鲜菌落要慢得多. 生产速率为 0.4, 规模 400 的嗜铁菌每 tick 产生 0.4 x 0.505 x 16.8 x 0.6 = 2.04 点进度: 每 2.5 秒一个铁锭, 每分钟约 24 个.

升级会乘到这些数值上. 满规模的钻石菌落配两个反应机速度升级时每分钟约产 97 个钻石, 配两个反应机产量升级时约 145 个, 因为此时每个循环产出 3 个.

满规模的嗜岩石菌落大约十秒就能填满 64 个物品的输出槽, 而槽满会使该菌落暂停, 因此要让产物持续运走.

## <Color id="gold">所需能量</Color>

能量是阈值. 反应机每 tick 都需要这么多 AP 到达, 否则什么都不会运行, 所有进度都会重置. 比这更强的光束会加快生产, 参见[更强的光束](nautec:getting_started/stronger_beams.md).

所需 AP = (基础值 + 每菌落值 x 已占用菌落槽数) x 升级倍率, 向上取整

| 反应机 | 基础值 | 每菌落 | 满员, 无升级 |
|---|---|---|---|
| 生物反应机 | 5 | 15 | 3 个菌落时 50 AP |
| 工业生物反应机 | 100 | 50 | 9 个菌落时 550 AP |

这四个数值均可配置. 空的菌落槽不计入. [反应机升级](reactor_upgrades.md)列出了各项倍率以及常见升级组合的消耗.
