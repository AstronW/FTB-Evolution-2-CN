<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">经验来源</Color>
</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

| 行为 | 体能经验 |
|---|---|
| 在地面疾跑 | 每秒约20 |
| 沿梯子,藤蔓或其他可攀爬方块向上攀爬 | 每秒约20 |
| 游泳(水中疾泳) | 每秒约2 |
| 跳跃 | 每次1 |
| 钓到鱼 | 每次5 |
| 钓到Starcatcher的鱼 | 每条10 |
| 赢得海蓝科技幸运区域小游戏 | 每次10 |

<ItemImage id="minecraft:air" scale="0.25"/>

只有实际移动的游戏刻才会获得移动经验,因此原地不动或乘坐载具都没有收益.走路,潜行,在水面划水和在水下行走也不计入;只有疾跑,向上攀爬和水中疾泳有效.
