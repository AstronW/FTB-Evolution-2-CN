# 反应堆资源端口

<BlockImage id="resource_port" scale="4" />

将**反应堆资源端口**安装到**外壳**上, 以在外部世界与反应堆之间传输物品和/或流体.

## 典型布局

### 手动 / 纯 RF(不需要端口)

燃料与废料可以通过[反应堆控制器](reactor_controller.md) GUI 处理. 你仍然需要至少一个[能量端口](power_ports.md).

### 自动化: 燃料输入 + 废料输出(**两个端口**, 与控制器同一面)

将**两个资源端口放在与反应堆控制器相同的墙上**. 示例见[入门](getting_started.md): 端口分散在该面上; 将鼠标悬停在场景中的菱形标记上可查看设置提示.

| 端口(示例) | 模式 | 过滤器 | 传输 |
|----------------|------|--------|-------|
| 左下 | **插入** | **燃料** | 固体燃料**进入**燃料棒 |
| 右下 | **抽取** | **废料** | **废料** **输出** |

在同一面再添加一个**能量端口**. 在每个端口的**外侧**连接管道/漏斗.

### 流体冷却剂回路(**额外端口**, 可选)

如果你使用**主动冷却剂**([入门](getting_started.md)中的方案 2):

- **插入**并选择**冷却剂**过滤器: 将冷却剂**输入**(*输入: 仅冷却剂流体.*)
- **抽取**并选择**冷却剂**过滤器: 将**蒸汽 / 用过的流体** **输出** → [涡轮机入门](../turbine/getting_started.md)(*输出: 仅用过的液态冷却剂.*)
- 将**抽取废料**保留在单独的端口上; 不要指望一个抽取端口排出不相关的流体.

## GUI: 按钮与提示

打开端口 GUI 并**悬停每个控件**; 下面的文字就是你在游戏内看到的内容.

### 模式(顶部按钮 - 点击循环)

| 标签 | 提示 |
|-------|---------|
| **插入** | 反应堆接收固体燃料与冷却剂流体. |
| **抽取** | 反应堆抽取核废料与用过的冷却剂流体. |
| **排出** | 反应堆排出内部储存的固体燃料. |

### 过滤器(仅反应堆 - 点击循环切换燃料 / 冷却剂角色)

取决于**模式**; 将鼠标悬停在按钮上可查看当前过滤器:

| 模式 | 过滤器标签 | 提示 |
|------|--------------|---------|
| **插入** | 全部 / 燃料 / 冷却剂 | *输入: 燃料与冷却剂.* / *输入: 仅燃料(物品或流体).* / *输入: 仅冷却剂流体.* |
| **抽取** | 全部 / 废料 / 冷却剂 | *输出: 固体废料与液态冷却剂.* / *输出: 仅固体废料.* / *输出: 仅用过的液态冷却剂.* |
| **排出** | 两者 / 仅燃料 / 仅冷却剂 | *排出: 燃料棒中的燃料物品与冷却剂流体.* / *排出: 仅燃料物品...* / *排出: 仅冷却剂流体.* |

### 介质开关(点击启用 - 激活时带下划线)

| 按钮 | 提示 |
|--------|---------|
| **固体** | 点击允许或阻止固体物品通过此端口. |
| **液体** | 点击允许或阻止流体通过此端口. |
| **气体** | 点击允许或阻止 Mekanism 气体通过此端口. |

### 储罐与清空

| 控件 | 提示 |
|---------|---------|
| **液体储罐**(悬停进度条) | 液体: 数量 / 容量 mB, 以及流体名称 |
| **气体储罐**(悬停进度条, Mekanism) | 气体: 数量 / 容量 mB, 以及气体名称 |
| 液体储罐下方的 **D** | 清空: 清空内部流体储罐(流体会被丢弃) |
| 气体储罐下方的 **D** | 清空: 清空气体储罐(气体会被丢弃) |

- **物品槽**: 手动输入/输出, 或在**外表面**使用漏斗/管道.

更改模式或过滤器后, 请**重启**[反应堆控制器](reactor_controller.md).

## 容量自动缩放

当反应堆**重新验证**时, 每个资源端口都会调整流体/气体储罐的大小(启用 Mekanism 气体时):

- 目标约为**该端口模式与过滤器的估算 mB/t × 10**, 每个储罐最低 **16,000 mB**.
- 大型反应堆的流体/气体容量**没有固定上限**.
- 需求增加时容量会**立即增长**; 只有当已储存内容仍能装入更小容量时才会**缩小**.
