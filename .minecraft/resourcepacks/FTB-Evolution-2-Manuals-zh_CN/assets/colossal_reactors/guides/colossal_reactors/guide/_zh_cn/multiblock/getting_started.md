# 入门: 你的第一座反应堆

建造一个封闭的反应堆外壳, 然后在下面两种方案中选择一种. 旋转场景以检查每个面.

## 外壳布局

- **地板与屋顶**: **反应堆外壳**(封闭框架).
- **竖直边角**: 四条边缘的**反应堆外壳**立柱(y=1-5).
- **西面, 东面和南面**: 每个面一块 **5×5 反应堆玻璃**面板(边角立柱之间为五行 × 五列).
- **控制器所在面**(示例中为北面): **反应堆控制器**向外凸出, 只占**单个方块**; 该面未安装端口的格子使用**反应堆玻璃**. **端口会替代玻璃**安装在该墙上, 与其他面做法相同, 并不是裸露的开口框架.
- **端口**: 位于**与控制器相同的墙面**, 可以放在该面的**任意位置**(示例有意将它们分散到远离控制器处).

[反应堆建造器](reactor_builder.md)会放置外壳, 玻璃(若缓冲区中有), 燃料棒和散热介质, 但**不会**放置控制器或端口.

## 散热介质与冷却剂

这是**两种不同的系统**:

| | **散热介质**(被动) | **冷却剂**(主动) |
|---|---|---|
| **是什么** | 燃料棒旁**外壳内部**的方块或**静止**液体填充 | 控制器缓冲区 / 资源端口回路中的工作**流体** |
| **如何放置** | 建造器 / 手动放入内部(包括"流体散热介质") | 控制器冷却剂槽, 或方案 2 中的 **插入/抽取** 端口 |
| **运行时消耗?** | **否** | **是**(并可能产生蒸汽 / 排出物) |
| **产出 RF 需要吗?** | 可选(会改变 RF 与燃料消耗) | 方案 1 **不需要** - 让冷却剂缓冲区保持**空** |

作为内部方块放置的流体散热介质**不**等同于把水接入冷却剂回路. 详情见[反应堆结构](reactor_structure.md).

## 方案 1: 简单能量(纯 RF)

当你只需要**反应堆产出的 RF**, 不需要蒸汽管线或涡轮机时使用此方案.

1. 建造外壳与内部结构(燃料棒 + 顶部的燃料棒控制器).
2. 按示例在同一面放置**控制器 + 能量端口**(控制器在**外侧**, 能量端口替代**玻璃**).
3. 让控制器的**冷却剂缓冲区保持空** - 不需要流体冷却剂.
4. 添加燃料(控制器 GUI 或漏斗/管道), 打开控制器 → **有效** → **开启**.
5. 将**能量端口的外侧**连接到接受能量的设备; 检查 **RF/t** &gt; 0.

**可选自动化**(示例中已展示): 在**同一面**放置两个**资源端口**, 并在每个端口的 GUI 中配置(**插入** / **抽取**, 过滤器, 介质开关). 每个按钮的说明见[资源端口 GUI 提示](resource_port.md). 更改端口模式后请**重启**.

| 端口(示例位置) | 模式 | 过滤器 |
|------|------|--------|
| 控制器所在面左下 | **插入** | **仅燃料** |
| 控制器所在面右下 | **抽取** | **两者**或仅固体 |
| 中央列, 控制器下方一格 | 能量端口 | - (输出 RF) |

手动游玩同样可行: 不使用资源端口, 直接在控制器中手动装入燃料.

## 方案 2: 冷却剂(为涡轮机提供蒸汽)

当水(或其他冷却剂)应当为[涡轮机](../turbine/getting_started.md)产生**蒸汽**, 而不是(或额外于)直接产出反应堆 RF 时使用此方案.

1. 建造相同的外壳, 并在同一面放置**控制器 + 能量端口**(能量端口对反应堆保留的任何 RF 仍然有用).
2. 在控制器中设置**冷却剂流体**(通常是**水** / 蒸汽模式).
3. 在**同一面**再添加**两个资源端口**(替代**玻璃**格子):
   - **插入**: **仅冷却剂**(或**两者**), 将冷却剂**输入**
   - **抽取**: **仅冷却剂**, 将**蒸汽 / 用过的流体** **输出**
4. 保留方案 1 中的**燃料插入**与**废料抽取**端口, 或手动处理燃料/废料.
5. 将反应堆**抽取**端口的**蒸汽**接入[涡轮机资源端口](../turbine/getting_started.md)(**插入**). 从涡轮机的**能量端口**获取 **RF**.

转化足够多时, 反应堆 **RF/t 可能下降**, 同时**蒸汽**上升, 这是正常的. 请按蒸汽量配置涡轮机与管道; 见[涡轮机入门](../turbine/getting_started.md).

更改冷却剂, 过滤器或端口模式后, 请**重启**反应堆控制器.

## 检查清单

1. 封闭外壳: 外壳地板/屋顶, 边角立柱, 三面墙上的 **5×5 玻璃**; 控制器所在面使用**玻璃 + 端口**(控制器单独位于外侧).
2. 在侧面安装**一个[反应堆控制器](reactor_controller.md)**, **单独**位于外壳外侧.
3. 在**同一面**安装**能量端口**(以及可选的资源端口).
4. 选择**方案 1**(空冷却剂)或**方案 2**(冷却剂回路 + 涡轮机).
5. **红石端口**是可选的.

## 反应堆建造器(可选)

1. 建造器只放置**内部结构 + 外壳**.
2. **停止**建造, 然后按场景在**同一面**添加控制器(外侧)与端口.
3. 从控制器进行验证.

## 反应堆无法启动?

| 症状 | 可能原因 |
|---------|----------------|
| 状态 **无效** | 修复外壳, 燃料棒或燃料棒控制器(查看状态行). |
| **开启**但 RF/t 为 0 | 没有能量端口或没有接受能量的设备; 或冷却剂模式缺少输入/抽取路径. |
| 一直**关闭**且有红石端口 | 端口上的红石设置 / 模式. |
| 没有废料输出 | 缺少**抽取**资源端口或过滤器错误. |
| 涡轮机没有蒸汽 | 未设置冷却剂, 插入被断供, 或缺少**抽取**冷却剂端口. |
