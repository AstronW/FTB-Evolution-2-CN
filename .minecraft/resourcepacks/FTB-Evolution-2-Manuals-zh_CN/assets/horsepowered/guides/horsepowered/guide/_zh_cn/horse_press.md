# 马匹压榨机

马匹压榨机是一台马力机器, 通过压榨物品来提取流体或产出其他产物. 适合提取油, 果汁和其他液体.

## 搭建

1. 把马匹压榨机放在周围至少有 7x7 空旷空间的区域.
2. 用拴绳牵引一匹马 (或其他有效生物).
3. 手持拴绳右键点击压榨机, 把生物拴上.
4. 生物会绕圈行走, 为压榨机提供动力.

## 检查工作区域

空手**Shift+右键点击**压榨机, 可显示所需的工作区域. 绿色 = 空旷, 红色 = 受阻.

## 用法

1. 手持物品右键点击以放入.
2. 手持装满的桶右键点击可为内部储罐注入, 手持空桶则可抽取.
3. 拴上的生物会自动压榨物品.
4. 右键点击以取出任何固体产物.

## 流体储罐

马匹压榨机有一个内部流体储罐, 用于产出和消耗流体:

- 配方可以注入储罐 (压榨种子可产出油), 也可以抽取储罐 (某些配方会消耗流体输入).
- 手持装满的桶右键点击可注入, 手持空桶则可抽取.
- 连接流体管道或储罐即可实现自动流体传输.

## 装瓶

桶之所以可用, 是因为游戏为它们提供了流体处理器能力. 玻璃瓶没有这种能力, 因此无法自行从储罐中取出流体. 压榨机通过装瓶配方列表来弥补这一点.

手持瓶子 (或配方指定的任何容器) 右键点击压榨机, 它会从输出储罐中抽取该配方所需的流体, 并交还装满的物品. 手持装满的物品右键点击则相反: 流体进入输入储罐, 你取回空容器.

默认自带一个装瓶配方: 一个玻璃瓶会从压榨机中取出 250 mB 的水, 变成水瓶. 请先压榨冰, 雪或滴水石以获取水.

整合包作者可以在 `data/<namespace>/recipe/bottling/<recipe>.json` 中添加更多配方:

```json
{
  "type": "horsepowered:bottling",
  "container": "minecraft:glass_bottle",
  "fluid": { "id": "minecraft:water", "amount": 250 },
  "result": {
    "id": "minecraft:potion",
    "components": { "minecraft:potion_contents": { "potion": "minecraft:water" } }
  }
}
```

* `container`: 原料. 玩家手持的空容器.
* `fluid`: 流体以及每次点击移动的量 (单位 mB).
* `result`: 交还的装满物品. 组件会被保留, 因此药水和其他携带数据的物品也能正常工作.
* `priority`: 可选, JEI 中的排序顺序. 数字越小越靠前.

通过这种方式, 可以让只以瓶装形式存在的流体 (果汁之类) 也能用手从压榨机中取出. JEI 会在 "装瓶" 分类下列出每个装瓶配方.

## 备注

- 压榨机有两格高.
- 部分配方需要多个输入物品, 或储罐中有特定流体.
- 空手右键点击可释放拴上的生物.
- 路径下方的地板会影响工作速度. 见[马匹路径与速度](horse_path.md).
- 可用的压榨配方可在 JEI/EMI 中查看.
